# Deploying for free (Render + Neon)

| Part | Free service |
|---|---|
| App (web page + API, built from the `Dockerfile`) | [Render](https://render.com) free web service: 512 MB RAM, no credit card |
| Database, including uploaded attachments | [Neon](https://neon.tech) free PostgreSQL: 0.5 GB |

Render's disk is wiped on every restart, so attachments are stored in the database. A sheet scan is tuned to
fit in 512 MB (`OCR_MAX_SIDE=1400`, `OCR_THREADS=1` in `render.yaml`): it peaks at about 430 MB and takes
about 35 seconds on the free plan's CPU share.

## 1. Database (Neon)

1. Sign up at <https://neon.tech> and create a project in an EU region.
2. Copy the connection string and change the start from `postgresql://` to `postgresql+psycopg://`, e.g.
   `postgresql+psycopg://user:password@ep-xxx.eu-central-1.aws.neon.tech/neondb?sslmode=require`.

The tables are created automatically on the first start. **Never put this URL in a tracked file** (such as
`.env.example`): for local use put it in `.env`, which git ignores.

## 2. App (Render)

1. Push this repository to GitHub, including `render.yaml`.
2. Sign up at <https://render.com> with GitHub (no card needed).
3. Click **New → Blueprint**, pick the repository, and fill in what it asks for:
   - `DATABASE_URL`: the Neon URL from step 1
   - `PROFESSOR_SIGNUP_CODE`: a code you give professors so they can register

   `JWT_SECRET` and `CODE_SECRET` are generated by Render, and `APP_ENV=production` is set.
4. Click **Apply**. The first build takes several minutes, and you can follow it in **Logs**.
5. Open `https://teamwork-attendance.onrender.com` (the exact address is shown on the service page) and
   check `/health`.

Every push to the main branch redeploys automatically.

## Things to know

- **Sleeping.** A free service sleeps after 15 minutes without visitors. The next visit takes about a minute
  to wake it, so open the site a minute before class. Neon also pauses when idle and resumes in about a
  second. No data is lost either way.
- **Monthly hours.** The free plan has 750 hours a month, enough for one service running all month.
- **Slow scans.** Reading a sheet photo takes about 35 seconds on the free plan. Don't refresh the page
  while it's working.
- **API docs.** With `APP_ENV=production`, `/docs` and `/redoc` are turned off. Run the app locally to see
  them.
- **Logs.** Use the **Logs** tab of the service in Render.
