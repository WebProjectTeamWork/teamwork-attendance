# Teamwork Attendance

Code/QR attendance for professors and students (FastAPI + PostgreSQL).

- Run locally: `docker compose up --build`, then open <http://localhost:8000>.
- Attendance reports in Grafana: <http://localhost:3000> (see [docs/reports-grafana.md](docs/reports-grafana.md)).
- Deploy for free (Render + Neon): see [docs/deploy-free.md](docs/deploy-free.md).
